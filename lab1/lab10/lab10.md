# Лабораторная работа 10. Система X Window

> **Примечание к оформлению.** Выводы команд ниже — типовые для Debian 13. Выполните команды на своей ВМ, сделайте
> скриншоты и замените ими заглушки `fig/...`. Графическую часть выполняйте на **консоли самой ВМ** (окно
> VirtualBox), а не в ssh-сеансе: `startx` запускает X-сервер на локальном экране машины. Если работать из macOS, нужен
> дополнительный X-сервер (XQuartz) — см. замечание в конце упр. 10.1.

> **Система X Window** (X11) — сетевая клиент-серверная графическая подсистема UNIX.
>
> * **X-сервер** (`Xorg`) управляет экраном, клавиатурой и мышью и рисует окна. Парадоксально, но «сервер» работает на
>   машине пользователя.
> * **X-клиенты** (`xterm`, `xclock`, …) — обычные программы, которые подключаются к серверу и просят его нарисовать
>   окна. Клиент может работать на другой машине.
> * **Оконный менеджер** (`blackbox`, `xfwm4`) — тоже X-клиент, который рисует рамки и заголовки окон и позволяет ими
>   управлять. Сам X-сервер этого не делает.
> * **Настольное окружение** (Xfce, GNOME) — оконный менеджер + панели, настройки, файловый менеджер и набор программ.
> * Переменная окружения **`DISPLAY`** (например, `:0`) указывает клиенту, к какому X-серверу подключаться.

## Упражнение 10.1. Создание собственного настольного окружения

### 1. Установите оконный менеджер blackbox

```bash
vlad@debian13:~$ sudo apt update
vlad@debian13:~$ sudo apt install xorg blackbox xterm x11-apps x11-xserver-utils xcalc
```

![install blackbox](fig/10-01%20install.png)

Назначение пакетов:

| Пакет               | Что даёт                                                       |
|:--------------------|:---------------------------------------------------------------|
| `xorg`              | X-сервер, драйверы, `startx`, `xinit`                          |
| `blackbox`          | лёгкий оконный менеджер                                        |
| `xterm`             | эмулятор терминала для X                                       |
| `x11-apps`          | набор простых клиентов: `xeyes`, `xclock`, …                   |
| `x11-xserver-utils` | утилиты `xsetroot`, `xrandr`, `xhost` и др.                    |
| `xcalc`             | калькулятор (в Debian может быть отдельным пакетом `x11-apps`) |

Проверка, что программы установлены:

```bash
vlad@debian13:~$ which blackbox xterm xeyes xclock xcalc xsetroot startx
/usr/bin/blackbox
/usr/bin/xterm
/usr/bin/xeyes
/usr/bin/xclock
/usr/bin/xcalc
/usr/bin/xsetroot
/usr/bin/startx
```

### 2. Сценарий .xinitrc

> `~/.xinitrc` — сценарий командного интерпретатора, который читает `startx` (`xinit`) после запуска X-сервера. Он
> формирует сеанс: запускает X-клиенты. **Сеанс живёт, пока работает последняя (не фоновая) команда сценария**, поэтому
> все клиенты запускаются в фоне (`&`), а оконный менеджер — последним, через `exec`. Закрытие оконного менеджера
> завершает весь графический сеанс.

```bash
vlad@debian13:~$ vim ~/.xinitrc
```

```bash
#!/bin/sh
# ~/.xinitrc - собственное настольное окружение (лаб. 10, упр. 10.1)

# a. цвет корневого окна (фона) darkslategray
xsetroot -solid darkslategray

# b. xterm в правом верхнем углу, символы white на фоне black
xterm -fg white -bg black -geometry 80x24-0+0 &

# c. xeyes в левом верхнем углу, размер 100x50 пикселей
xeyes -geometry 100x50+0+0 &

# d. xclock в правом нижнем углу, размер 50x50 пикселей
xclock -geometry 50x50-0-0 &

# e. xcalc в левом нижнем углу
xcalc -geometry +0-0 &

# оконный менеджер - последним, в основном процессе
exec blackbox
```

![.xinitrc](fig/10-01%20xinitrc.png)

Разбор:

- `xsetroot -solid darkslategray` — залить корневое окно (фон рабочего стола) сплошным цветом; названия цветов берутся
  из `/usr/share/X11/rgb.txt`.
- Параметр `-geometry ШИРИНАxВЫСОТА±X±Y` — размер и положение окна:
    * `+X`/`+Y` — отступ от **левого**/ **верхнего** края экрана, `-X`/`-Y` — отступ от **правого**/ **нижнего** края;
    * поэтому `-0+0` — правый верхний угол, `+0+0` — левый верхний, `-0-0` — правый нижний, `+0-0` — левый нижний;
    * для обычных программ (`xeyes`, `xclock`) размер задаётся в **пикселях**, а для `xterm` — в **символах**
      (80 столбцов × 24 строки).
- `-fg` / `-bg` — цвет переднего плана (символов) и фона.
- `exec blackbox` — заменяет процесс сценария оконным менеджером; когда `blackbox` завершится (пункт меню Exit),
  завершится
  и X-сеанс.

Сценарий не обязан быть исполняемым: `startx` запускает его через `sh`. На всякий случай:

```bash
vlad@debian13:~$ chmod +x ~/.xinitrc
```

### 3. Запуск графической подсистемы

```bash
vlad@debian13:~$ startx
```

(На консоли ВМ, например `tty1`; если вход был по ssh, получим ошибку `Cannot open virtual console` или
`no screens found`.)

После нескольких секунд (появляются сообщения `xinit`/`Xorg` и экран переключается в графический режим) активизируется
созданное окружение:

- тёмно-серо-зелёный (`darkslategray`) фон;
- `xterm` с белым текстом на чёрном фоне в правом верхнем углу;
- глаза `xeyes`, следящие за курсором мыши, в левом верхнем углу;
- маленькие часы `xclock` в правом нижнем углу;
- калькулятор `xcalc` в левом нижнем углу;
- рамки и заголовки окон рисует `blackbox`; панель инструментов — внизу экрана. Правый щелчок по свободному месту
  фона вызывает меню `blackbox` (запуск программ, смена стилей, пункт **Exit**).

![startx](fig/10-01%20startx.png)

Активное настольное окружение — **собственное, на базе оконного менеджера Blackbox**: ни панели задач, ни меню «Пуск»
(кроме меню по щелчку на фоне), ни файлового менеджера нет — только те клиенты, которые запущены в `.xinitrc`.

Проверка из `xterm`:

```bash
vlad@debian13:~$ echo $DISPLAY
:0
vlad@debian13:~$ ps aux | grep -E 'Xorg|blackbox|xclock' | grep -v grep
vlad  1234  ... /usr/lib/xorg/Xorg :0 vt1 ...
vlad  1250  ... blackbox
vlad  1255  ... xclock -geometry 50x50-0-0
```

Завершение сеанса: правый щелчок по фону → **Exit** (либо `^C` на консоли, с которой запускался `startx`).

> **Замечание для macOS / WSL.** На macOS или Windows (WSL) сначала устанавливается внешний X-сервер (XQuartz / VcXsrv),
> затем подключение выполняется по ssh с пересылкой X11: `ssh -X vlad@<адрес>`, после чего клиенты (`xclock`,
> `xterm`) запускаются на ВМ, а окна отображаются на экране хозяина: `echo $DISPLAY` покажет `localhost:10.0`.
> Полноценное
> настольное окружение через `startx` при этом не запускается, а проверяются отдельные клиенты:
> ```bash
> vlad@debian13:~$ xclock -geometry 50x50-0-0 &
> vlad@debian13:~$ xeyes -geometry 100x50+0+0 &
> ```
> Для пересылки X11 на сервере должно быть `X11Forwarding yes` в `/etc/ssh/sshd_config` и установлен пакет `xauth`.

## Упражнение 10.2. Настройка настольного окружения Xfce

> **Xfce** — лёгкое полнофункциональное настольное окружение: оконный менеджер `xfwm4`, панель `xfce4-panel`, менеджер
> рабочего стола `xfdesktop`, файловый менеджер `Thunar`, терминал, набор настроек (`xfce4-settings`).

### 1. Создайте сценарий .xinitrc, всегда запускающий Xfce

```bash
vlad@debian13:~$ sudo apt install xfce4 xfce4-terminal
vlad@debian13:~$ mv ~/.xinitrc ~/.xinitrc.blackbox      # сохраняем предыдущий сценарий
vlad@debian13:~$ vim ~/.xinitrc
```

```bash
#!/bin/sh
# ~/.xinitrc - всегда запускать настольное окружение Xfce
exec startxfce4
```

![.xinitrc xfce](fig/10-02%20xinitrc.png)

- `startxfce4` — штатный сценарий запуска сеанса Xfce: он поднимает `xfce4-session`, который, в свою очередь,
  запускает оконный менеджер, панель и менеджер рабочего стола.
- `exec` заменяет процесс сценария сеансом Xfce; выход из Xfce (Log Out) завершает X-сервер.

Запуск:

```bash
vlad@debian13:~$ startx
```

Появляется рабочий стол Xfce: панель сверху (меню приложений, список окон, область уведомлений, часы), док внизу,
значки «Домашняя папка», «Файловая система», «Корзина».

![xfce](fig/10-02%20xfce.png)

### 2. Настройка Xfce «по вкусу»

Настройки открываются через **Меню приложений → Параметры → Диспетчер настроек** (`xfce4-settings-manager`). Выполнено:

- **Рабочий стол (Desktop)** — сменён фон на сплошной цвет / изображение;
- **Внешний вид (Appearance)** — тема оформления (стиль, значки, шрифт) на тёмную;
- **Панель (Panel)** — добавлен индикатор загрузки процессора (`CPU Graph`) и перенесена панель вниз;
- **Клавиатура** — добавлена русская раскладка с переключением `Alt+Shift`;
- **Эмулятор терминала** — изменены цвета и размер шрифта.

![xfce customized](fig/10-02%20xfce%20custom.png)

Все параметры сохраняются в каталоге пользователя `~/.config/xfce4/` (XML-файлы каналов `xfconf`) и при следующем входе
восстанавливаются автоматически:

```bash
vlad@debian13:~$ ls ~/.config/xfce4/xfconf/xfce-perchannel-xml/
xfce4-desktop.xml  xfce4-panel.xml  xfwm4.xml  xsettings.xml ...
```

### 3. Закончите графический сеанс

**Меню приложений → Выйти (Log Out) → Выйти**. X-сервер завершается, возвращается консольное приглашение:

```bash
vlad@debian13:~$
```

## Упражнение 10.3. Графический вход в систему

> **Менеджер дисплеев (Display Manager, DM)** — служба, которая запускает X-сервер при загрузке системы, показывает
> графическое окно входа (имя + пароль) и по результату аутентификации запускает сеанс выбранного пользователем
> окружения. Примеры: `lightdm`, `gdm3`, `sddm`, `xdm`. В отличие от `startx`, DM **не читает** `~/.xinitrc` —
> сеанс выбирается из списка в окне входа (файлы `/usr/share/xsessions/*.desktop`).

### 1. Автоматический запуск графической среды с менеджером дисплеев

Узнаём, установлен ли менеджер дисплеев и какая цель загрузки (target) используется:

```bash
vlad@debian13:~$ cat /etc/X11/default-display-manager
cat: /etc/X11/default-display-manager: Нет такого файла или каталога
vlad@debian13:~$ systemctl get-default
multi-user.target
```

`multi-user.target` — многопользовательский текстовый режим (приглашение `login:` на консоли, как в лаб. 1).

Устанавливаем менеджер дисплеев `lightdm` (лёгкий, хорошо сочетается с Xfce) и его приветствие:

```bash
vlad@debian13:~$ sudo apt install lightdm lightdm-gtk-greeter
```

![install lightdm](fig/10-03%20install%20lightdm.png)

При установке нескольких DM система спросит, какой использовать по умолчанию — выбираем `lightdm`.

Включаем автозапуск и устанавливаем графическую цель по умолчанию:

```bash
vlad@debian13:~$ sudo systemctl enable lightdm
vlad@debian13:~$ sudo systemctl set-default graphical.target
Removed '/etc/systemd/system/default.target'.
Created symlink '/etc/systemd/system/default.target' → '/usr/lib/systemd/system/graphical.target'.
vlad@debian13:~$ systemctl get-default
graphical.target
vlad@debian13:~$ cat /etc/X11/default-display-manager
/usr/sbin/lightdm
```

![graphical target](fig/10-03%20graphical.png)

- `systemctl enable` — запускать службу при каждой загрузке;
- `graphical.target` — цель загрузки «многопользовательский режим + графический вход»; она требует, чтобы был запущен
  менеджер дисплеев (`display-manager.service`);
- `/etc/X11/default-display-manager` — путь к используемому DM (его определяет конфигурация пакета; сменить можно
  командой `sudo dpkg-reconfigure lightdm`).

> **Возврат к текстовому входу** (если понадобится): `sudo systemctl set-default multi-user.target`.

### 2. Перезагрузка, проверка графического входа

```bash
vlad@debian13:~$ sudo reboot
```

После загрузки вместо текстового `login:` появляется графическое окно входа LightDM. В нём:

1. в нижней или верхней части окна открываем выбор сеанса (значок шестерёнки/списка) и выбираем **Xfce Session**;
2. вводим имя `vlad` и пароль;
3. загружается настольное окружение Xfce — с теми же настройками, что и в упр. 10.2.

![lightdm login](fig/10-03%20lightdm.png)

Проверка запущенных служб (из терминала Xfce или с консоли `Ctrl+Alt+F2`):

```bash
vlad@debian13:~$ systemctl status lightdm | head -4
● lightdm.service - Light Display Manager
     Loaded: loaded (/usr/lib/systemd/system/lightdm.service; enabled; preset: enabled)
     Active: active (running) since Mon 2026-10-12 21:05:11 EEST; 3min ago
vlad@debian13:~$ echo $XDG_SESSION_TYPE $XDG_CURRENT_DESKTOP
x11 XFCE
```

Текстовая консоль по-прежнему доступна на других виртуальных терминалах: `Ctrl+Alt+F2` (графика при этом занимает
`tty7`, в Debian 13 — `tty1`/`tty7` в зависимости от запуска), вернуться — `Ctrl+Alt+F7` (или `F1`).

### 3. Закончите графический сеанс

**Меню приложений → Выйти → Выйти** — сеанс закрывается, менеджер дисплеев снова показывает окно входа:

![logout](fig/10-03%20logout.png)

### Сравнение способов запуска графики

| Критерий              | `startx` + `.xinitrc`                    | Менеджер дисплеев (`lightdm`)             |
|:----------------------|:-----------------------------------------|:------------------------------------------|
| **Когда запускается** | вручную, после входа в текстовую консоль | автоматически при загрузке системы        |
| **Вход в систему**    | текстовый (`login:`)                     | графическое окно входа                    |
| **Выбор окружения**   | содержимое `~/.xinitrc`                  | список сеансов в окне входа               |
| **Сеанс закрывается** | завершением последней команды `.xinitrc` | пунктом «Выйти», DM показывает окно входа |
| **Применение**        | минимальные и самодельные окружения      | обычные настольные системы                |
