# Лабораторная работа 3. Пользовательское окружение. Пользовательский профиль

## Упражнение 3.1. Переменные окружения. Переменные командного интерпретатора

1. Посмотрите значение переменных окружения с помощью команды env. Зафиксируйте
значения переменных окружения PATH, LANG, TERM:

![env](fig/01%20env.png)

- `env` - выводит все переменные окружения текущего процесса

```bash
PATH=/usr/local/bin:/usr/bin:/bin:/usr/local/games:/usr/games:/usr/sbin:/sbin:/usr/games:/usr/sbin:/sbin:/usr/games:/usr/bin:/bin
LANG=en_US.UTF-8
TERM=xterm-256color
```

- `PATH` — список каталогов, в которых shell ищет исполняемые файлы при вводе команды
- `LANG` — задаёт локаль, которая по умолчанию
- `TERM` — указывает тип терминала, с которым сейчас работает пользователь

2. Установите в переменную окружения PATH пустое значение.
3. Проследите за реакцией различных команд (date, man, ...). Зафиксируйте произошедшие изменения:

Выводятся сообщения, что команды не найдены. (`-bash: info: No such file or directory`)

![PATH=](fig/01%20PATH=.png.png)

4. Восстановите старое значение переменной окружения PATH.
5. Установите в переменную окружения LANG значение любого языка в формате язык_[СТРАНА.[кодировка]].

```bash
vlad@debian13:~$ export LANG=ru_RU.UTF-8
```

`export` помечает переменную для передачи во все дочерние процессы, то есть передает изменения во все остальные команды 
cal, date и тп.

6. Проследите за реакцией различных команд (date, man, ...). Зафиксируйте произошедшие изменения:

Вывод всех команд стал на русском языке.

![LANG=ru_US.UTF-8](fig/01%20LANG.png)

7. Восстановите старое значение переменной окружения LANG.
8. Установите в переменную окружения TERM значение vt100.
9. Проследите за реакцией различных команд (mcedit, man, ...). Зафиксируйте произошедшие изменения:

Исчезает форматирование текста, визуальное отображение становиться менее красивым. В man ломается листание страниц, в 
mcedit меняется цвет фона и становится невозможен выход из приложения.

![mcedit vt100](fig/01%20mcedit%20vt100.png)

![mcedit xterm-256color](fig/01%20mcedit%20xterm-256color.png)

10.  Восстановите старое значение переменной окружения TERM.
11.  Посмотрите значение внутренних переменных командного интерпретатора bash с помощью команды set. Зафиксируйте 
значение переменной PS1:

`PS1` - Prompt String 1, определяет вид приглашения командной строки,

![PS1](fig/01%20PS1.png)
```bash
PS1='\[\e]0;\u@\h: \w\a\]${debian_chroot:+($debian_chroot)}\[\033[01;32m\]\u@\h\[\033[00m\]:\[\033[01;34m\]\w\[\033[00m\]\$ '
```

12.  Установите во внутреннюю переменную PS1 любое значение.

```bash
vlad@debian13:~$ PS1='MyShell>'
```

13.  Проследите за реакцией командного интерпретатора. Зафиксируйте произошедшие изменения:

![01 PS1=MyShell>.png](fig/01%20PS1%3DMyShell%3E.png)
После выполнения `PS1='MyShell> '` приглашение командной строки изменилось на `MyShell> `

## Упражнение 3.2. Конфигурационные файлы пользовательского окружения. Пользовательский профиль.

1. Создайте файл .plan в домашнем каталоге пользователя. Запишите в него любую информацию.

Для создания файла была использована следующая команда: 
```bash
touch .plan
```
Файл `.plan` - файла, в котором пользователь мог записать свои текущие дела.

2. При помощи команды finger посмотрите и зафиксируйте изменения в свойствах пользователя student:

Примечание: если используется интерпретатор отличный от bash, то данные файлы не будут считаны, используйте .profile или
специфичный для вашего интерпретатора файл конфигурации. 
Запишите в файл команду присвоения в переменной окружения LANG значение любого языка в формате язык_[СТРАНА.[кодировка]]:

настройки рабочей среды.
