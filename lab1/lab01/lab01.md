# Лабораторная работа 1. Интерактивная работа в системе. Пользовательская учетная запись

## Упражнение 1.1. Загрузка операционной системы. Вход в систему

1. Включите компьютер.
2. В приглашении загрузчика выбора операционной системы выберите Linux.
3. Проследите за сообщениями системы, выдаваемыми в процессе загрузки. Появление приглашения к вводу имени пользователя, означает окончание процесса загрузки системы. Примечание 1: для отображения полного лога загрузки ОС требуется убрать параметр ядра quite. Примечание 2: если по умолчанию установлен графический вход в ОС, переключитесь на виртуальную консоль сочетанием клавиш “Ctrl-Alt-F1” или “Ctrl-Alt-F2”.
4. Зафиксируйте приглашение к вводу имени пользователя и расшифруйте его составляющие:
![Приглашение к вводу имени пользователя](fig/01%20prompt%20to%20enter%20the%20user%20name.png)

```bash
Debian GNU/Linux 13 debian13 tty1

debian13 login:
```  

- `Debian GNU/Linux 13` - название и версия операционной системы.
- `debian13` - имя виртуальной машины (компьютера).
- `tty1` - teletypewriter, имя текущего терминала.
- `login:` - поле для ввода имени пользователя, под которым будет осуществлен вход.

5. В приглашении к вводу имени пользователя введите имя учетной записи student или
другую доступную учетную запись

6. Зафиксируйте приглашение к вводу пароля и расшифруйте его составляющие:
![Приглашение к вводу пароля](fig/01%20password%20prompt.png)

```bash
debian13 login: vlad
Password:
```  

- В поле Password необходимо ввести пароль. Вводимые символы пароля не отображаются, для того, чтобы нельзя было понять длину пароля. Пароль проверяется посимвольно.

7. В приглашении к вводу пароля введите password или другой установленный пароль. В
случае правильного ввода имени пользователя и пароля появится приглашение к вводу
команд.

8. Зафиксируйте появившиеся сообщения и приглашение к вводу команд и расшифруйте
его составляющие:
![Приглашение к вводу команд](fig/01%20prompt%20to%20enter%20commands.png)

```bash
Debian GNU/Linux 13 debianis tty1

debian13 login: vlad
Password:
Linux debian13 6.12.107+deb13-arm64 #1 SMP Debian 6.12.107-1 (2026-08-29) aarch64

The programs included with the Debian GNU/Linux system are free software; 
the exact distribution terms for each program are described in the 
individual files in /usr/share/doc/*/copyright.

Debian GNU/Linux comes with ABSOLUTELY NO WARRANTY, to the extent 
permitted by applicable law. 
vlad@debian13:~$
```

- `Linux debian13 6.12.107+deb13-arm64...` - описание ядра Linux и информация об архитектуре процессора.
- `The programs included with the...` - стандартное описание Debian. (Программы, входящие в состав системы Debian GNU/Linux, являются свободным программным обеспечением; точные условия распространения каждой программы описаны в отдельных файлах в /usr/share/doc/*/copyright. Debian GNU/Linux поставляется без КАКИХ-либо ГАРАНТИЙ, в той мере, в какой это разрешено применимым законодательством.)
- `vlad` - имя текущего пользователя
- `debian13` - имя виртуальной машины
- `~` - текущая директория (в данном случае домашний каталог пользователя)
- `$` - приглашение для ввода команды пользователю (если бы был root, то был символ `#`)

## Упражнение 1.2. Виртуальные терминалы

1. Используя клавиши Alt+Fx, Alt+←, Alt+→ переключитесь и войдите в систему на 2-ом,
4-ом и 6-ом терминале. Примечание: если работаете в графической системе для
перехода используйте сочетание “Ctrl-Alt+Fx”.
2. Зафиксируйте появляющееся сообщение от системы:

Вход в дополнительные терминалы я делал после проброса ssh с физического компьютера на виртуальную машину. В терминале virtual box мне удалось открыть только два терминала `tty1` и `tty2`, с помощью комбинации `fn + control + option + f2`. В терминале macOS с проброшенным ssh удалось открыть 6, как и требовалось в задании.

![Дополнительный терминал](fig/02%20terminal.png)

Сохраняются все те же сообщения системы, что и ранее, только дополнительно еще выводится информация о последнем входе в систему (дата, время и ip-адрес устройства с которого было выполнено подключение)

3. Проследите за появившимися приглашениями к вводу команд.
4. При помощи команды tty, получите и зафиксируйте информацию о 2-ом, 4-ом и 6-ом
виртуальном терминале соответственно:

![Терминал-2](fig/02%20tty2.png)

![Терминал-4](fig/02%20tty4.png)

![Терминал-6](fig/02%20tty6.png)

```bash
vlad@debian13:~$ tty
/dev/pts/0
```

- `tty` - команда (teletypewriter) запрашивает у системы через какой какой терминал происходит работа
- `/dev/pts/0` - вывод команды, означает, что в данном случае используется самый первый созданный терминал. `pts` (pseudo-teletype slave) означает, что я использую псевдо-терминал, то есть работаю в терминале через ssh. Если работать с терминала VB, то вывод будет таким: `/dev/tty1`

5. Вернитесь на терминал #1
6. При помощи команды clear очистите терминал, проследите за реакцией системы

Команда `clear` очищает терминал и выводит новое приглашение в вводу команд.

Примечание: если данное упражнение невыполнимо с использованием виртуальных
терминалов, например, при использовании MacOS X или WSL, то выполните tty для
эмулятора терминала.

## Упражнение 1.4. Команды для получения информации о системе и работающих пользователях

При помощи следующих команд: `whoami`, `id`, `users`, `who`, `w`, `date`, `cal`, `uname`, `uptime` получите информацию о системе и пользователях и зафиксируйте ее:

- имя текущего пользователя:
`whoami` - команда, которая выводит имя пользователя текущего сеанса, если ввести команду `sudo whoami`, то будет выведено имя `root` (`sudo` - superuser do)

![whoami](fig/04%20whoami.png)

- его идентификаторы UID, GID и идентификаторы вторичных групп:
`id` - команда, которая выводит информацию о uid, gid и о всех группах, в которых состоит пользователь. `uid` - Unique IDentifier, уникальный числовой идентификатор пользователя. `gid` - Group IDentifier, определяет принадлежность пользователя к группе для управления правами доступа. `groups` - список всех групп, в которые входит пользователь.

![id](fig/04%20id.png)

- количество и имена пользователей, работающих в системе, их терминалы, время
работы в системе и время входа в систему, выполняемые команды:
`users` - список имен пользователей, которые вошли в систему и имеют активный сеанс
`who` - показывает активные сеансы
`w` - показывает время, количество пользователей, активные сеансы, информацию о загрузке системы и активности каждого пользователя. `USER` - имя пользователя, `TTY` - терминал сеанса,  `FROM` — адрес источника подключения, `LOGIN@` — время входа, `IDLE` — время бездействия (сколько времени прошло с последнего ввода), `JCPU` — суммарное процессорное время всех процессов, запущенных в этом сеансе, `PCPU` — процессорное время текущего активного процесса, `WHAT` — команда, которую пользователь выполняет в данный момент

![users](fig/04%20users.png)

![who](fig/04%20who.png)

![w](fig/04%20w.png)

- системная дата и время:
`date` - выводит дату и время

![date](fig/04%20date.png)

- календарь текущего месяца:
`cal` - команда выводит календарь. Изначально команда не была установлена на Debian-13. Используя команду `sudo apt install ncal` была произведена установка.

![cal](fig/04%20cal.png)

![cal -y](fig/04%20cal%20-y.png)

- версия операционной системы компьютера:
`uname` - информация об операционной системе машины. Флаг `-a` выведет полное название операционной системы

![uname](fig/04%20uname.png)

![uname -a](fig/04%20uname%20-a.png)

- время работы операционной системы от момента запуска и нагрузку на
операционную систему
`uptime` - выводит время работы операционной системы и нагрузку на нее

![uptime](fig/04%20uptime.png)
