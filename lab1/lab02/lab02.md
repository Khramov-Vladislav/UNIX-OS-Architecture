## Упражнение 2.1. Страницы электронного руководства UNIX

1. При помощи команды: man man ознакомтесь со справкой по команде man.
Зафиксируйте назначение команды man:

`man` - manual, интерфейс к встроенной справочной системе UNIX/Linux, хранящей описания команд, системных вызовов, конфигурационных файлов и других аспектов системы в виде отформатированных man-страниц (manual pages)

2. Страницы руководства выводятся на терминал постранично при помощи программы
постраничной разбивки (PAGER). Вызовите встроенную справку по программе
постраничной разбивки с помощью клавиши h. Ознакомьтесь с основами работы со
справочной системой и зафиксируйте основные комбинации клавиш, используемые для
навигации и поиска в справочной системе, а именно:

- клавиши построчного и постраничного листания вверх и вниз:
  - `j` - на одну строку вниз
  - `k` - на одну строку вверх
  - `f` - на страницу (экран) вниз
  - `b` - на страницу (экран) вверх
  - `d` - на полстраницы вниз
  - `u` - на полстраницы вверх
  - `g` - в начало документа
  - `G` - в конец документа

- клавишу выхода из справочной системы:
  - `q` - выход из просмотра man-страницы

- клавиши поиска информации в странице руководства:
  - `/pattern` - поиск вперёд по документу (от текущей позиции к концу)
  - `?pattern` - поиск назад по документу (от текущей позиции к началу)

- клавиши повторения предыдущего поиска:
  - `n` - повторить последний поиск в том же направлении
  - `N` - повторить последний поиск в противоположном направлении

3. При помощи клавиш поиска и повторения поиска найдите на текущей странице все появления слова page, зафиксируйте использованные сочетания клавиш:

`/page` - используется для поиск слова page. 

4. При помощи команды: man <номер раздела> intro ознакомьтесь с назначением всех
восьми разделов справочной системы. Зафиксируйте их назначение:

| Раздел | Назначение |
| --- | ---------- |
| 1 | Команды пользователя |
| 2 | Системные вызовы |
| 3 | Библиотечные функции |
| 4 | Специальные файлы и драйверы устройств |
| 5 | Форматы файлов |
| 6 | Игры |
| 7 | Дополнительная информация |
| 8 | Команды администрирования системы |

5. При помощи команды: whatis получите краткую справку по всем известным вам командам. Зафиксируйте и расшифруйте составляющие нескольких описаний команд:

`whatis` — выводит краткое описание команды

![whatis](<fig/01 whatis.png>)

```bash

```

6. При помощи команды: apropos воспользуйтесь контекстным поиском справочной
информации по любому ключевому слову. Зафиксируйте и расшифруйте составляющие
нескольких найденных ссылок:

`apropos` - ищет заданное слово в описаниях всех man-страниц.
