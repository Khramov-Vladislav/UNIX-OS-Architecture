# Лабораторная работа №5. Сетевой чат

`chatd` обслуживает TCP-соединения в одном процессе. Слушающий и принятые сокеты переводятся в режим `O_NONBLOCK` через `fcntl()`. Как на слайдах 30–42 лекции, `select()` сообщает, какие сокеты готовы к чтению. Сервер также следит за готовностью к записи, когда в очереди клиента есть данные. После частичной отправки остаток остаётся в очереди до следующей готовности, а `EAGAIN` и `EWOULDBLOCK` возвращают управление циклу событий.

Протокол построчный. Сервер собирает неполную строку между вызовами `recv()` и обрабатывает несколько строк, пришедших за один вызов. Разделители строк — LF и CRLF. Максимальная длина входной строки — 1024 байта без разделителя. Сервер одновременно обслуживает до 64 подключений и отключает клиента, если его очередь отправки переполняется.

## Сборка и запуск

Из корня репозитория запустите:

```sh
cd lab5
make
pid=$(./chatd) && printf 'PID: %s\n' "$pid"
```

По умолчанию демон слушает `127.0.0.1:3425` и при успешном запуске печатает PID. `-a IPv4` задаёт адрес прослушивания, `-p PORT` задаёт порт, `-f` оставляет сервер на переднем плане. Например, `./chatd -f -a 0.0.0.0 -p 3426` принимает подключения на всех локальных IPv4-интерфейсах через порт `3426`.

Сообщения о запуске, остановке и ошибках записываются через `syslog` с тегом `chatd`. В режиме `-f` они также выводятся в `stderr`. На Debian журнал можно посмотреть через `journalctl -t chatd`. Для остановки демона выполните `kill -TERM "$pid"`.

## Команды чата

- `/nick NAME` регистрирует имя. Оно должно быть уникальным и содержать от 1 до 20 символов из `A–Z`, `a–z`, `0–9`, `_` и `-`.
- `/who` показывает имена подключённых участников.
- Обычная строка рассылается всем зарегистрированным участникам, включая отправителя.
- `/msg NAME TEXT` ставит личное сообщение в очередь выбранного участника.
- `/quit` закрывает подключение.

## Ручная проверка

Запустите три клиента в разных терминалах из каталога `lab5`. Используйте `./chat` для подключения к адресу по умолчанию или `./chat HOST PORT` для другого адреса. Тот же построчный протокол доступен через `nc 127.0.0.1 3425`.

1. Введите `/nick alice`, `/nick bob` и `/nick carol` в терминалах соответствующих клиентов.
2. Отправьте от `alice` строку `Всем привет!`. Все три клиента должны получить `ALL alice: Всем привет!`.
3. Отправьте от `alice` команду `/msg bob Личное сообщение`. `bob` должен получить `FROM alice: Личное сообщение`, а `alice` — подтверждение постановки в очередь. У `carol` новой строки не появится.
4. Введите `/quit` у `bob`. Команда `/who` у `alice` должна показать `alice` и `carol`. Общие сообщения по-прежнему должны доходить до обоих участников.
